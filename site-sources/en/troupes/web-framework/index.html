Purpose§

The Web Framework Troupe maintain the software that powers many of the Raku websites.

The Web Framework Troupe has two major projects:

  • raku.org (the main website)
  • Elucid8 (for documentation)

raku.org§

This is the main Raku website. Its purpose is to welcome newcomers to Raku, and draw them into the community.

Elucid8 (for documentation)§

This is only the software for making the documentation website. For the actual documentation, see the Documentation Troupe.

The main website for this software is at elucid8.org. Reading that would be a worthwhile introduction to the project.
